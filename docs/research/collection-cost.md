B안 = 330,967원 + 1,886원 × N         (고정비 + 변동비)

## 5. B안에서 LLM을 부르는 시점

"공지를 볼 때마다 LLM을 부르면 비싸지 않나?"라는 오해를 막기 위해 단계별로 나눴습니다.

| 단계 | LLM 호출 | 사람 시간 |
| --- | --- | --- |
| ① 프롬프트·스키마·검증기 설계 | X | 7h |
| ② 최초 규칙 생성 (150개 일괄) | O (한 번만) | 0h (실행 대기) |
| ③ 결과 점검·보정 | X | 5.5h |
| ④ 평소 공지 수집·분류 | **X — 만들어 둔 규칙을 코드로 실행** | 0h |
| ⑤ 규칙이 깨졌을 때 재생성 | O (해당 게시판만) | 게시판당 3분 |

LLM은 **규칙을 만들 때만** 부릅니다. 만들어진 규칙은 코드로 실행하므로, 평소 수집에는 토큰 비용이 들지 않습니다. 사람이 규칙을 쓰느냐 AI가 쓰느냐의 문제가 아니라, **규칙을 누가 쓰고 누가 검수하느냐**의 문제로 본 것입니다.
