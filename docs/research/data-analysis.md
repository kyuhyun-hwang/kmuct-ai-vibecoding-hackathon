# 공지 데이터 수집·분석

2026-09-16 ~ 09-17 · 대상: 국민대 게시판 30곳의 2026-02-01 ~ 04-30 공지 939건

이 문서는 문제 정의와 설계 결정의 근거가 된 데이터 분석을 정리한 것입니다. 원자료(크롤링 결과, 분석 JSON)는 학교 공지 원문이 들어 있어 레포에 포함하지 않았습니다.

## 1. 수집 대상 정하기 (사전 조사)

### 사이트 조사
- kookmin.ac.kr 도메인을 가진 사이트를 찾아 셌습니다. **도메인 75개, 공지 게시판 150개**입니다.
- 경영대 학생 페르소나를 기준으로 사이트 **43곳**을 골라 하나씩 조사했습니다. 조사한 항목은 다음과 같습니다.
  - robots.txt 규칙
  - 게시판 구조(목록 URL, 페이지 넘김 방식, 상세 URL 패턴, 날짜 형식)
  - 자바스크립트 렌더링이 필요한지
  - 마지막 게시일
  - 다른 게시판을 그대로 복사한 미러 게시판인지
- 게시판은 사이트 구조에 따라 **7종**으로 나눴습니다. 같은 학교 안에서도 게시판 시스템이 이만큼 제각각입니다.

### 제외한 곳
41곳을 점검 대상으로 표시했고, 그중 **32곳을 수집에서 뺐습니다.**

| 사유 | 내용 |
|---|---|
| 미러 게시판 | 본부 게시판을 그대로 가져와 보여주는 게시판. 본부 게시판과 글 ID, 제목, 날짜가 같은지 확인하고 제외함. 넣으면 같은 공지가 여러 번 셈해짐 |
| robots.txt 전체 차단 | 모든 경로의 수집을 막아 둔 사이트 |
| 접속 불가 | DNS 조회 실패 |

최종 수집 대상은 **게시판 30곳**이고, 사이트 구조는 6종입니다([`app/sites.json`](../../app/sites.json)). 수집은 Claude Code로 구조별 수집 코드를 만들어 진행했습니다.

## 2. 분석 방법

- **LLM을 쓰지 않고 정규식 규칙으로만 셌습니다.** 같은 데이터에 같은 규칙을 돌리면 같은 숫자가 나오게 하려고, 규칙 전문을 결과와 함께 남겼습니다.
- 판정은 "이 표현이 제목과 본문 어딘가에 한 번이라도 나오는가"의 예/아니오입니다. 등장 횟수는 세지 않았습니다.
- 표본을 직접 읽어 보면서 오탐(잘못 잡힌 것)을 찾았고, 오탐을 없애는 규칙을 추가한 뒤 다시 셌습니다(v1 → v2).

### 자격 조건 7개 유형과 규칙

| 유형 | 정규식 (요약) |
|---|---|
| 1. 신청 대상 명시 | `신청대상\|지원대상\|모집대상\|지원자격\|신청자격 …` |
| 2. 학년·학적 | `\d\s*학년\|재학생\|휴학\|복학\|졸업예정\|학기\s*이상 …` |
| 3. 성적 | `평점\|학점\|성적\|GPA\|직전학기\|이수학점 …` |
| 4. 소득·경제 | `소득분위\|기초생활\|차상위\|국가장학\|학자금지원구간 …` |
| 5. 소속 | `단과대\|학과\|전공\|학부\|계열\|소속` |
| 6. 배제·중복 | `중복수혜\|제외\|불가\|이미\s*수혜\|타\s*장학 …` |
| 7. 제출 서류 | `제출서류\|구비서류\|증빙\|신청방법\|접수처 …` |

## 3. 결과

### 3-1. 자격 조건: 공지의 절반 이상은 따져 봐야 지원할 수 있다

| 지표 | 전체 939건 | 장학 관련 106건 |
|---|---:|---:|
| 조건(유형 2~6)이 하나 이상 있음 | **55%** (518건) | 58% |
| 조건이 세 개 이상 있음 | 22% (210건) | **38%** |
| 학년·학적 조건 | 44% | 48% |
| 소속 조건 | 33% | 34% |
| 배제·중복 조건 | 26% | **42%** |
| 성적 조건 | 23% | 33% |
| 소득 조건 | 3% | **23%** |
| 제출 서류 | 25% | 42% |

- 장학 공지는 조건이 더 많고 복잡했습니다. 조건이 세 개 이상인 비율이 전체의 1.7배이고, 소득 조건은 7배였습니다.

### 3-2. 글로 된 내용이 없다: 텍스트만 읽어서는 판단할 수 없다

| 지표 | 값 |
|---|---:|
| 7개 유형 중 어느 것도 잡히지 않은 공지 | **38%** (360건) |
| 그 공지들의 본문 길이 중앙값 | **0자** |
| 본문이 50자도 안 되는 공지 | 33% |
| 한글(HWP) 첨부 | 첨부 224개 중 78개 |

조건 표현이 하나도 안 잡힌 공지는 대부분 조건이 없어서가 아니었습니다. **본문 자체가 비어 있었습니다.** 내용이 포스터 이미지나 첨부파일에만 있다는 뜻입니다. 그래서 서비스에서는 첨부 변환 텍스트와 이미지 판독 텍스트까지 원문 저장본으로 남기도록 설계했습니다.

### 3-3. 조건이 공지 밖에 있다

| 지표 | 값 |
|---|---:|
| 외부 참조가 하나 이상 있는 공지 | **59%** (555건) |
| 담당자 연락처(전화 또는 이메일) | 33% |
| 외부 URL | 32% |
| "자세한 내용은 ~ 참조" 같은 유도 표현 | 17% |

공지 열 건 중 여섯 건은 학생을 다른 곳(외부 사이트, 담당자 전화)으로 보냅니다. 전화로 직접 확인해 본 결과는 [`problem-validation.md`](problem-validation.md)에 있습니다.

### 3-4. 장학 게시판만 봐서는 장학 공지를 다 볼 수 없다

- 16개 장학 키워드로 찾은 뒤 오탐을 걸러, 장학 관련 공지는 **106건**이었습니다(v1 112건에서 오탐 6건 제외).
- 그중 본부 장학공지 게시판에 있는 것은 82건(**77%**)입니다.
- 나머지 **24건(23%)**은 법대, 경영대, 생활관, 학사공지 등 다른 게시판에만 있었습니다. 그 24건 중 20건은 장학 게시판에 다시 올라오지 않은, 그 게시판에만 있는 공지였습니다.

**장학 게시판만 꼼꼼히 봐도 장학 공지 다섯 건 중 한 건은 놓칩니다.** 공지를 모아 둔 사이트가 있어도 흩어짐 문제가 해결되지 않는다는 근거입니다.

### 3-5. 마감일이 안 보인다

| 지표 | 값 |
|---|---:|
| 제목에 마감일이 있는 공지 | **19%** (177건) |
| 제목이나 본문 어딘가에 마감일이 있는 공지 | 39% |
| 텍스트 어디에도 마감일이 없는 공지 | **61%** (573건) |
| 장학 공지 중 제목에 마감일이 있는 것 | 10% |

- 마감일 표기 형식도 `(~5/12)`, `[~05.08.]`, `(4.30(목)까지)`, `5월 11일까지`처럼 제각각이라 형식별 정규식 9개를 만들어 셌습니다.
- 공지 목록만 보고는 지금 신청할 수 있는지 알 수 없습니다. 그래서 신청 기간을 공지 카드에 따로 뽑아 두고, 모집 중인 공지만 보여주고 마감순으로 정렬하도록 했습니다.

## 4. 분석이 설계로 이어진 곳

| 분석 결과 | 설계 결정 |
|---|---|
| 조건이 있는 공지 55% | 모아 보여주기가 아니라 **자격 판정**을 서비스의 중심에 둠 |
| 유형별 비율 | 판정할 조건 유형과 우선순위를 정함 |
| 본문이 빈 공지 38%(중앙값 0자), HWP 첨부 35% | 첨부와 이미지 판독까지 **원문 저장본**으로 남김 |
| 배제·중복 조건 26%(장학은 42%) | 프로필에 없는 조건은 "지원 불가"가 아니라 **되묻기** 대상으로 둠 |
| 외부 참조 59% | 판정마다 **근거 원문**을 함께 보여줌. 공지에 없는 조건은 검토 대기열로 보냄 |
| 장학 공지 23%가 장학 게시판 밖에 있음 | 게시판 30곳을 **한 목록으로 통합**하고 중복 게시는 하나로 합침 |
| 마감일이 텍스트에 없는 공지 61% | 신청 기간을 카드에 따로 정리하고 마감순으로 보여줌 |

## 5. 한계

- **정규식 판정의 오탐:** 예를 들어 "제외", "불가"는 "주차 불가", "환불 불가"처럼 자격과 상관없는 문맥에서도 잡힙니다. 사후에 숫자를 맞추려고 규칙을 덧대지 않았고, 표본을 직접 읽어서 확인할 수 있게 남겼습니다.
- **기간:** 2026년 2~4월, 개강 전후 3개월만 봤습니다. 다른 시기에는 비율이 다를 수 있습니다.
- **범위:** 경영대 학생 페르소나를 기준으로 게시판 30곳을 골랐습니다. 학교 전체 게시판 150개를 대표하지는 않습니다.
